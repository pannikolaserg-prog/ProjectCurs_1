Описание:
ProjectCurs_1 - это приложение для анализа транзакций, которые находятся в Excel-файле. Приложение генерирует JSON-данные для веб-страниц, 
формирует Excel-отчеты, а также предоставляет другие сервисы.
Установка:
1. Клонируйте репозиторий:
git@github.com:pannikolaserg-prog/ProjectCurs_1.git
Использование:
1. Откройте приложение в вашем PyCharm.
2. В модуле views.py реализована функция для генерации JSON-ответов, а также функционал для главной страницы.
3. В модуле reports.py отображаются траты за последние 3 месяца.
4. В модуле utils.py расположены все остальные функции для работы приложения.
